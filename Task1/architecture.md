Для предъявленных требований по доступности (99,9% для 24/7) и отказоустройчивости (RTO — 45 мин., RPO — 15 мин) лучшим вариантом 
является использование фейловер-стратегии *Active-Active*. Также с учетом требований по геодоступности, имеет смысл выбрать 
вариант с георезервированием, что дополнительно позволит обеспечить одинаковое время загрузки страниц для пользователей из разных регионов.   
Для масштабирования при росте нагрузки предлагается использовать горизонтальное, которое лучше подходит для микросервисной архитектуры.
